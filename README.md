# Changelog Component

## Project Overview

This project involves creating a modern, accessible, and responsive **Changelog Component** using HTML, CSS, and JavaScript. The primary objective is to present product updates, new features, bug fixes, and release notes in a clean, chronologically structured feed layout.

The project focuses on building a semantic and accessible web component while applying essential frontend practices such as SEO meta tags, Open Graph (OG) integration for social sharing, favicon implementation, responsive layout optimization, and interactive JavaScript features.

## Project Requirements

* **Semantic HTML**
  Use semantic HTML elements to structure content sections such as the header, changelog release feed, release tags, and footer.

* **Search Engine Optimization (SEO) Meta Tags**
  Include essential metadata inside the head section to improve discoverability and search engine indexing.

* **Open Graph (OG) Tags**
  Implement Open Graph tags to provide optimized previews when sharing links on social media platforms.

* **Favicon**
  Add a favicon for better branding and browser recognition.

* **Responsive Layout Preparation**
  Organize the CSS grid and flexbox structure to support all screen dimensions, from desktop down to mobile devices.

* **Interactive Elements**
  Include JavaScript functionality for dynamic behaviors such as category filtering (e.g., Features, Fixes, Improvements) or interactive UI state toggles.

## Project Structure

* **Homepage (`index.html`)**
  The primary HTML document containing the changelog feed, filter buttons, version tags, and release details.

* **Styles (`css/style.css`)**
  Contains custom CSS styling, layout positioning, responsive media queries, typography, and visual enhancements.

* **Scripts (`js/script.js`)**
  Handles client-side interactivity, event listeners, and dynamic UI updates.

* **Assets (`assets/`)**
  Directory containing project assets including `favicon/`, `logo/`, `open-graph/`, and `project-preview.png`.

## How to Use

1. Clone or download this repository.

```bash
git clone https://github.com/aditnurdiansyah/changelog-component
```

2. Navigate to the project folder.

```bash
cd changelog-component
```

3. Open `index.html` in your browser.

4. Customize the changelog entries, version tags, and styling based on your product needs.
